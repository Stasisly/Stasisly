# STASISLY-AGENTS-003: Wave 2 Governance, Security and Founder Prompts

## Objective and scope

This package approves the documentary prompt baseline for exactly 18 agents,
`AG-TRV-0002` through `AG-TRV-0019`. It migrates six audited historical
sources, creates twelve new catalog-derived prompts and resolves the
`AG-TRV-0003` Transversal reclassification. Historical source files remain
unchanged.

## Coverage and authority

The cohort covers global governance, facilitation, strategy, security, privacy,
AppSec, cryptography, ethics, compliance, critical escalation, enterprise risk,
evidence, portability and cross-surface contracts. Founder remains external.
Standard, Elevated and Emergency modes are distinct; privileged and Emergency
actions require exact external authorization, minimum privilege, expiry,
evidence and audit. No prompt grants access.

Security, Privacy, Audit and Risk preserve independent challenge and separation
of duties. Every prompt declares data, tool and memory ceilings while keeping
actual provisioning at zero.

## Development Surface decision

Development Surface will provide a conversational, visual, governed, traceable
and auditable interface for developing Stasisly. The intended loop is Founder
intention, Rector, minimum sufficient team, isolated execution, validation,
correction, evidence, approval where required, commit and authorized deployment.
Git remains canonical source control. The loop continues until readiness or a
real blocker. Neither the surface nor `dev.stasisly.com` is implemented here.
