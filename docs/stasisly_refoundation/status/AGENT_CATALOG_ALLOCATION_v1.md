Counts represent catalog capacity, not active processes, licenses or concurrent
model calls. The maximum future catalog is unbounded and governed by coverage,
risk, quality and cost evidence.

Default activation is `MINIMUM_SUFFICIENT_TEAM`. Reallocation does not require
preserving these exact proportions, but any change must retain the total and
explain coverage impact until a replacement baseline is approved.
