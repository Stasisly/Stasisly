# ADR-RF068 - W7-001 Administration Fraud and Risk Specialized Prompt Baseline

Decision: APPROVED

W7-001 establishes individual composable documentary prompts for the exact forty HIGH-risk Administration `fraud_risk` agents resolved by the approved Wave 7 strategy. Shared components do not replace identity, composition, evaluation or P0-P14 approval per agent.

```text
Implementation: DOCUMENTARY_PROMPTS_IMPLEMENTED
FRAUD_RUNTIME_NOT_IMPLEMENTED
ENFORCEMENT_NOT_IMPLEMENTED
TOOLS_NOT_PROVISIONED
AGENTS_NOT_AVAILABLE
```
