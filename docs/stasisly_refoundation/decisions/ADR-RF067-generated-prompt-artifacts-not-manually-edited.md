# ADR-RF067 - Generated Prompt Artifacts Are Not Manually Edited

Decision: APPROVED

Generated manifests and effective prompts are derived artifacts. Changes must
occur in source components or generation rules, then be regenerated, validated
and reviewed with impact evidence. Direct edits are forbidden.

```text
STRATEGY_AND_ARCHITECTURE_DOCUMENTED
SPECIALIZED_PROMPTS_NOT_CREATED
RUNTIME_NOT_IMPLEMENTED
AGENTS_NOT_AVAILABLE
```
