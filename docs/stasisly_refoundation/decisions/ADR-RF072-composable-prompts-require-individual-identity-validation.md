# ADR-RF072 - Composable Specialized Prompts Require Individual Identity and Validation

Decision: APPROVED

Family, module and overlay reuse never approves an agent collectively. Every composed specialist requires its own identity contract, effective prompt, manifest, evaluation, adversarial cases, reinforced HIGH review and P0-P14 evidence.

```text
Implementation: DOCUMENTARY_PROMPTS_IMPLEMENTED
FRAUD_RUNTIME_NOT_IMPLEMENTED
ENFORCEMENT_NOT_IMPLEMENTED
TOOLS_NOT_PROVISIONED
AGENTS_NOT_AVAILABLE
```
