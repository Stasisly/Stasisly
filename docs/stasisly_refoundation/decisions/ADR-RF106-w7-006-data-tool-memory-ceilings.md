# ADR-RF106 - W7-006 Data Tool and Memory Ceilings

## Decision

APPROVED

Catalog data access is `NO_USER_DATA`. Tool classes are ceilings rather than
grants and remain unprovisioned. Raw payment credentials, user payment data,
production access, mutation and retention expansion are forbidden; memory is
unprovisioned and task-bounded.

## Implementation

```text
DOCUMENTARY_PROMPTS_IMPLEMENTED
RUNTIME_NOT_IMPLEMENTED
TOOLS_NOT_PROVISIONED
MEMORY_NOT_PROVISIONED
MODELS_NOT_CONFIGURED
AGENTS_NOT_AVAILABLE
```
