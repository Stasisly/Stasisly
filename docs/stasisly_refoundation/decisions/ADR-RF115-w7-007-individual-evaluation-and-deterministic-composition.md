# ADR-RF115 - W7-007 Individual Evaluation and Deterministic Composition

## Decision

APPROVED

Shared family, module and overlay approval never substitutes individual review.
Each W7-007 agent passes 32 sections, P0-P14, ten domain adversarial cases and
nine CRITICAL reviews. Canonical assembly and component hashes must regenerate
byte-identically.
