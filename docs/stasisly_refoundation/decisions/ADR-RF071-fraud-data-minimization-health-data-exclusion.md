# ADR-RF071 - Fraud Analysis Must Minimize Data and Exclude Health Data by Default

Decision: APPROVED

Fraud analysis applies purpose limitation, minimization, need-to-know access, retention limits, access logging and user rights. Health, wellness, private conversations and unrelated Product memory are denied by default; future exceptions require legal basis, strict necessity, explicit scope and separate authority.
