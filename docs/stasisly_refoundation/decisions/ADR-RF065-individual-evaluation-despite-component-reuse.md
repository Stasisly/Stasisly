# ADR-RF065 - Individual Evaluation Despite Component Reuse

Decision: APPROVED

Approval of a shared family, module or overlay does not approve an agent.
Every effective agent prompt requires individual composition, authority, risk,
evaluation and adversarial evidence through P0-P14 before `PROMPT_CREATED`.

```text
STRATEGY_AND_ARCHITECTURE_DOCUMENTED
SPECIALIZED_PROMPTS_NOT_CREATED
RUNTIME_NOT_IMPLEMENTED
AGENTS_NOT_AVAILABLE
```
