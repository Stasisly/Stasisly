# ADR-RF073 - Generated Effective Prompts and Manifests Are Deterministic Artifacts

Decision: APPROVED

W7-001 effective prompts and manifests are generated from ordered, versioned components and identity contracts. Canonical hash inputs make identical sources byte-stable. Generated effective prompts are not manually edited; component changes use the impact index and regeneration.

```text
Implementation: DOCUMENTARY_PROMPTS_IMPLEMENTED
FRAUD_RUNTIME_NOT_IMPLEMENTED
ENFORCEMENT_NOT_IMPLEMENTED
TOOLS_NOT_PROVISIONED
AGENTS_NOT_AVAILABLE
```
