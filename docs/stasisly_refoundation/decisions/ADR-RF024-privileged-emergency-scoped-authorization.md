# ADR-RF024: Privileged and Emergency Operations Require Explicit Scoped Authorization

## Decision

`APPROVED` on 2026-07-31.

Elevated and Emergency operations require external Founder authorization bound
to purpose, resources, environment, duration and evidence. Emergency additionally
requires necessity, containment, expiry and retrospective review. No prompt or
catalog class grants privileged access.
