# ADR-RF032 - Data Router and Shard Directory Contracts

Status: `APPROVED`

## Decision

Data Router and Shard Directory are future internal, versioned contracts for routing and placement. Both are `NOT_IMPLEMENTED`; no current request depends on them. `RUNTIME_NOT_IMPLEMENTED`; `AGENTS_NOT_AVAILABLE`.

## Consequences

Routing preserves authorization, residency, provenance and rollback. Their names do not prove deployment.
