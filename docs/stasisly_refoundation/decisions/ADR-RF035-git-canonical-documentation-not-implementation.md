# ADR-RF035 - Git Canonical and Documentation Not Implementation

Status: `APPROVED`

## Decision

Git is the canonical source for versioned architecture, prompts and contracts. A documented component is not implemented, configured, deployed, available or authorized without separate evidence. `RUNTIME_NOT_IMPLEMENTED`; `AGENTS_NOT_AVAILABLE`.

## Consequences

Every future runtime claim requires code, configuration, tests, deployment evidence and an approved lifecycle transition.
