# ADR-RF045: Development Surface Is the Primary Governed Engineering Interface

## Status

Decision: `APPROVED`

Implementation:

```text
DOCUMENTARY_PROMPTS_IMPLEMENTED
DEVELOPMENT_SURFACE_NOT_IMPLEMENTED
RUNNERS_NOT_IMPLEMENTED
RUNTIME_NOT_IMPLEMENTED
AGENTS_NOT_AVAILABLE
```

## Decision

Development is the primary governed interface for technical work. Rector coordinates bounded decomposition from Founder intention through evidence, review and authorization without inheriting Founder authority.

## Consequences

Product and Administration retain independent boundaries. The interface and orchestration remain architecture targets, not operational capabilities.
