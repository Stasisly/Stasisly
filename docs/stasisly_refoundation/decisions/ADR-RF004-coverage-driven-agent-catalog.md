# ADR-RF004 - Coverage-driven 3,000-agent initial catalog

## Status

`Decision: APPROVED`

`Implementation: PLANNED`

## Decision

Establish an initial catalog baseline of 3,000 capability slots: Product 1,050,
Development 1,200, Administration 700 and Transversal 50. The distribution is
provisional, coverage-driven and not a simultaneous activation target.

Prompts are generated only after taxonomy, naming, duplication, lifecycle and
activation rules are approved.
