# ADR-RF134 - W7-010 Data Tool and Memory Ceilings

## Decision

APPROVED

`SENSITIVE_HEALTH_DATA`, catalog tool classes and catalog memory scopes are
ceilings, not grants. Evidence remains purpose-limited, minimum-necessary,
redacted, consent-aware and user/tenant/case-scoped. Tools and memory are not
provisioned; record and production mutation are forbidden.

## Implementation

```text
DOCUMENTARY_PROMPTS_IMPLEMENTED
RUNTIME_NOT_IMPLEMENTED
TOOLS_NOT_PROVISIONED
MEMORY_NOT_PROVISIONED
MODELS_NOT_CONFIGURED
AGENTS_NOT_AVAILABLE
```
