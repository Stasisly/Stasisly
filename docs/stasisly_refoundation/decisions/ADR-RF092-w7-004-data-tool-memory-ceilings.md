# ADR-RF092 - W7-004 Data Tool and Memory Ceilings

## Decision

APPROVED

Catalog data, tool and memory classes are ceilings, not grants. Financial data
is purpose-limited, minimized, redacted and need-to-know. Composition selects
the most restrictive ceiling and cannot provision credentials, tools, memory,
mutation or durable retention.

## Implementation

```text
DOCUMENTARY_PROMPTS_IMPLEMENTED
RUNTIME_NOT_IMPLEMENTED
TOOLS_NOT_PROVISIONED
MEMORY_NOT_PROVISIONED
AGENTS_NOT_AVAILABLE
```
