# ADR-RF001 - Start Re-foundation and archive previous baseline

## Status

`Decision: APPROVED`

`Implementation: DOCUMENTED`

## Decision

Start Stasisly Re-foundation as the current normative documentary stage.
Discovery and Foundation materials remain preserved, read-only references and
non-normative. Nothing is deleted or moved until a controlled archive package
is approved.

## Consequences

New work follows Re-foundation sources. Historical evidence remains available
for audit and selective adoption but cannot silently override current decisions.
