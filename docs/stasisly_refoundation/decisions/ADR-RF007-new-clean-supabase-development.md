# ADR-RF007 - New clean Supabase Development project

## Status

`Decision: APPROVED`

`Implementation: NOT_IMPLEMENTED`

## Decision

Plan a new clean Development project after Re-foundation. It starts with new
credentials, clean Auth and Storage, migration history from `00001`, synthetic
seeds, explicit RLS and surface access.

This ADR does not create the project or authorize remote work. The existing
project remains a non-normative read-only candidate pending inventory/export.
