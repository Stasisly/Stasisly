# ADR-RF108 - W7-006 Individual Evaluation and Deterministic Composition

## Decision

APPROVED

Shared component approval cannot replace individual validation. Each W7-006
agent passes P0-P14, eight adversarial cases and six HIGH reviews. Manifests bind
component and identity hashes, and two generations must remain byte-stable.
