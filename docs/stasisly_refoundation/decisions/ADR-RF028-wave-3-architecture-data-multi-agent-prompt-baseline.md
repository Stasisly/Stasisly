# ADR-RF028 - Wave 3 Architecture, Data and Multi-Agent Prompt Baseline

Status: `APPROVED`

## Decision

Approve the 40 exact Wave 3 prompts and evaluations as a documentary baseline under `STASISLY-AGENTS-004`. They are `DOCUMENTED_ONLY`, `RUNTIME_NOT_IMPLEMENTED` and `AGENTS_NOT_AVAILABLE`.
