# ADR-RF063 - Prompt Components Cannot Elevate Authority

Decision: APPROVED

Family, specialty, identity, runtime, task and temporary components may narrow
authority, data, tool or memory scope but cannot elevate a higher-level ceiling.
The most restrictive applicable rule wins and conflicts fail closed.

```text
STRATEGY_AND_ARCHITECTURE_DOCUMENTED
SPECIALIZED_PROMPTS_NOT_CREATED
RUNTIME_NOT_IMPLEMENTED
AGENTS_NOT_AVAILABLE
```
