# ADR-RF086 - Sensitive Health and Private Data Require Strict Need-to-Know Access

Decision: APPROVED

## Decision

Health, wellness, mental-health, biometric, precise-location, identity, financial, children, private-communication, Founder-private and security-restricted data require purpose limitation, minimization, need-to-know, legal basis and controlled disclosure.
