# ADR-RF062 - Individual Agent Identity Is Mandatory

Decision: APPROVED

Shared families and modules never replace an individual identity contract.
Every catalog agent retains its own mission, scope, exclusions, reporting,
authority ceilings, escalation path, risk tier and lifecycle state.
