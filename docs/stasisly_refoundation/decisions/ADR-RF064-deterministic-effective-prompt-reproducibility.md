# ADR-RF064 - Deterministic Effective Prompt Reproducibility

Decision: APPROVED

Effective prompts require ordered components, canonical serialization,
component versions and content hashes. Identical inputs must reproduce the same
manifest and effective hash. Generated outputs are never manually edited.

```text
STRATEGY_AND_ARCHITECTURE_DOCUMENTED
SPECIALIZED_PROMPTS_NOT_CREATED
RUNTIME_NOT_IMPLEMENTED
AGENTS_NOT_AVAILABLE
```
