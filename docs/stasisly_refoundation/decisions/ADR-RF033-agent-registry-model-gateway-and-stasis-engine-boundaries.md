# ADR-RF033 - Agent Registry, Model Gateway and Stasis Engine Boundaries

Status: `APPROVED`

## Decision

Agent Registry, Model Gateway and Stasis Engine are internal platform components and currently `NOT_IMPLEMENTED`. Stasis Engine is not a surface, database or client authority. `RUNTIME_NOT_IMPLEMENTED`; `AGENTS_NOT_AVAILABLE`.

## Consequences

Catalog identity, prompt approval, runtime configuration, model binding, tool binding and availability remain distinct states.
