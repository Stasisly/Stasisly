# ADR-RF026: Development Surface as the Governed Interface for Building Stasisly

## Decision

`APPROVED` on 2026-07-31.

Development Surface is intended to develop, maintain and evolve Stasisly from
a conversational, visual, governed, traceable and auditable interface. Founder
intention flows through Rector to the minimum sufficient technical team,
isolated execution, validation, correction, evidence, approval, commit and
authorized deployment.

## Consequences

```text
Implementation: DOCUMENTARY_PROMPTS_IMPLEMENTED
Development Surface: DEVELOPMENT_SURFACE_NOT_IMPLEMENTED
Runtime: RUNTIME_NOT_IMPLEMENTED
Availability: AGENTS_NOT_AVAILABLE
```

This decision does not implement `dev.stasisly.com` or any runtime surface.
