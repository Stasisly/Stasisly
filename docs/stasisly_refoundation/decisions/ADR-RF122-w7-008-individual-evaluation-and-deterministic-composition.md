# ADR-RF122 - W7-008 Individual Evaluation and Deterministic Composition

## Decision

APPROVED

Shared family, module and overlay approval never substitutes individual review.
Each W7-008 agent passes 32 sections, P0-P14, ten health adversarial cases and
six HIGH or eight CRITICAL reviews. Canonical assembly and component hashes must
regenerate byte-identically.
