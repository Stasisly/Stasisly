# ADR-RF113 - W7-007 Data Tool and Memory Ceilings

## Decision

APPROVED

`SECURITY_RESTRICTED_DATA`, `SECURITY_RESTRICTED_TOOLS` and catalog memory
scopes are ceilings, not grants. Evidence remains purpose-limited, minimized,
redacted and case-scoped. Raw credentials, secrets and keys are forbidden;
tools and memory are not provisioned.

## Implementation

```text
DOCUMENTARY_PROMPTS_IMPLEMENTED
RUNTIME_NOT_IMPLEMENTED
TOOLS_NOT_PROVISIONED
MEMORY_NOT_PROVISIONED
MODELS_NOT_CONFIGURED
AGENTS_NOT_AVAILABLE
```
