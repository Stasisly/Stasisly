# ADR-RF061 - Composable Specialized Prompt Architecture

Decision: APPROVED

An effective prompt is assembled from versioned constitutional, surface,
domain, family, specialty, identity, overlay, runtime, task and temporary
components. Missing or incompatible required components fail closed.

```text
STRATEGY_AND_ARCHITECTURE_DOCUMENTED
SPECIALIZED_PROMPTS_NOT_CREATED
RUNTIME_NOT_IMPLEMENTED
AGENTS_NOT_AVAILABLE
```
